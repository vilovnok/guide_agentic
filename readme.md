# Guide agentic

Пошаговый гайд по созданию простых агентов с полноценным harness (обвязкой): от чат-цикла до мультиагентной системы с памятью, расписанием и несколькими каналами. Каждый шаг — отдельная папка с работающим кодом, который расширяет предыдущий.

## Структура туториала

### Фаза 1: один способный агент (шаги 0–6)

Полноценный агент: чат, инструменты, навыки, память диалога, интернет.

| Шаг | Тема | Что получаем |
|-----|------|--------------|
| [chat_loop](https://) | Чат-цикл | Просто чат-цикл |
| [tools](https://github.com/) | Инструменты | Даём агенту инструмент |
| [skills](https://github.com/) | Навыки | Расширение через `SKILL.md` |
| [persistence](https://github.com/) | Персистентность | Сохранение переписки |
